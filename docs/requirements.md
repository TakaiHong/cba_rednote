# 需求说明

## 业务目标

为新加坡迷你仓业务搭建一个低成本、可持续运行的小红书内容平台。平台每天产出可发布的图文草稿，帮助触达短期回国、租房断档、搬家延期、装修暂存、合租变动和大件物品存放等人群，并把内容效果沉淀下来，用于后续复盘和选题优化。

## 产品定位

- 核心卖点：便宜、灵活、省心。
- 服务模式：支持自己运，也支持帮运。
- 主要场景：短期回中国、房子到期但新房未定、毕业或假期退宿舍、临时出差、装修腾房、大件家具或行李暂存。
- 内容语气：自然、直白、生活化，不只做硬广。
- 内容方向：用故事、避坑、清单、对比、评论互动和直接促销等多种方式软植入迷你仓服务。

## 目标人群

- 留学生：暑假或毕业回国，宿舍退租，行李和家具没有地方放。
- 上班族：短期回国、出差、换租、工作地点变化，需要临时存放物品。
- 租房断档人群：旧房到期，新房还没定，行李需要过渡空间。
- 大件存放人群：床垫、桌椅、显示器、自行车、行李箱、季节性用品等不方便带走或丢弃的物品。
- 临时需求人群：装修、合租变动、房东收房、搬家延期、家庭空间不足等。

## 内容生成要求

- 每天自动生成至少 1 条小红书草稿。
- 支持后端 cron 或 Windows 任务计划程序执行每日生成。
- 每条内容包含标题、正文、标签、CTA、目标人群、内容角度和图片建议。
- 每条内容提供封面文字、视觉 brief、AI 出图 prompt 和素材清单，方便后续拍摄、制图或发布。
- 平台支持用草稿内容生成低成本 3:4 PNG 模板封面，作为小红书封面占位或轻量运营图。
- 每条内容可以绑定本地图片素材路径，发布脚本 dry-run、发布包和辅助发布会复用这些素材。
- 内容风格需要多样化，至少覆盖故事型、攻略型、避坑型、清单型、对比型、直白促销型和评论互动型。
- 生成时尽量避免与历史标题和正文高度重复。
- 支持本地模板生成，也支持 DeepSeek/OpenAI-compatible 低成本模型生成。
- 单条付费模型文案成本预算控制在 0.5 元人民币以内。
- 支持批量生成一周内容，并限制批量任务里最多多少条使用付费模型。

## 平台功能要求

- 前端运营台支持查看、筛选、搜索、编辑、生成和批量生成草稿。
- 前端运营台支持查看内容效果概览，包括曝光、点赞、收藏、评论、关注和咨询数。
- 前端运营台支持人工录入发布链接和发布后的效果指标。
- 后端 API 负责草稿管理、内容生成、内容批量生成、状态更新、发布包输出和系统状态汇总。
- 系统状态需要展示内容数量、最近草稿、配置状态、成本汇总、运行记录和下一步内容建议。
- 关键动作需要记录运行日志，便于确认每日任务、生成、发布回写和交接包导出是否成功。

## 发布要求

- 发布脚本支持一键读取指定草稿，生成小红书发布包，并打开小红书创作者中心。
- 默认采用半自动发布：脚本填充或复制标题、正文和标签，由人工检查后最终点击发布。
- 支持图片目录输入，也支持读取草稿里绑定的本地图片素材，把可用图片上传到发布页面。
- 支持真实账号预检，输出选择器可用性报告。
- 最终点击发布必须有双重确认：命令行显式传入发布参数，并设置环境变量允许最终发布。
- 在没有真实账号验证前，不强制承诺全自动发布。

## 文档与工程要求

- 文档需要包含需求说明、架构说明、代码地图、发布流程和运营手册。
- 项目需要提供本地启动、健康检查、完整验证、正式上线检查、备份、定时任务安装和 handoff 交接命令。
- 项目需要由本地 Git 管理，每次可交付改动都应提交。
- 不能把真实 API key 提交到仓库；DeepSeek key 只能放在 `.env` 或当前 shell 环境变量中。

## 验收标准

- `npm.cmd run verify` 通过。
- `npm.cmd run go-live:check` 在真实账号 preflight 和已发布 URL 都补齐后通过。
- `npm.cmd run health` 能确认前端和后端在线。
- `npm.cmd run readiness` 没有 required failure。
- 可以生成单条草稿和 7 天批量草稿 dry-run。
- 可以导出最新草稿的 Markdown 发布包。
- 可以生成 handoff 包，供运营或发布人员接手。
- 可以运行 `publish:preflight`，并在真实已登录小红书账号中得到选择器验证报告。
- 至少有一条人工审核后的发布链接被回填到运营台或通过 CLI 标记为已发布。

## 第一版非目标

- 不绕过小红书风控。
- 不在没有账号验证的情况下默认全自动点击发布。
- 不依赖昂贵模型作为唯一生成路径。
- 不在第一版里建设复杂 CRM、支付、仓库库存管理或客服工单系统。
