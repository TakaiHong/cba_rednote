# Requirements

## Business Goal

为新加坡迷你仓业务持续生产小红书内容，吸引短期回中国、租房断档、搬家、装修、存放大件物品等人群咨询迷你仓服务。

## Positioning

- 核心卖点：便宜、灵活、省心。
- 服务模式：自己运和帮运两种选项。
- 语气：自然、直白、多样，不只硬营销。
- 内容形式：标题、正文、标签、图片建议、目标人群、发布状态。

## Target Segments

- 留学生：暑假或毕业短期回国，宿舍退租，行李无处放。
- 上班族：短期回国、出差、换租、工作地点变化。
- 租房断档人群：旧房到期，新房还没定。
- 大件存放人群：床垫、桌椅、显示器、自行车、行李箱。
- 临时需求人群：装修、合租变动、房东收房、搬家延迟。

## Content Requirements

- 每天自动生成至少 1 条小红书草稿。
- 每条包含标题、正文、标签、图片建议、CTA、目标人群和内容角度。
- 支持不同内容风格：故事、攻略、避坑、清单、对比、直白促销、评论互动。
- 记录生成成本估算，并控制在 0.5 元人民币以内。
- 支持人工编辑后发布。

## Platform Requirements

- 前端运营台查看、筛选、编辑、生成、标记状态。
- 后端 API 负责草稿管理、内容生成、定时任务和发布数据输出。
- 发布脚本支持一键读取草稿并打开小红书创作者中心半自动发布。
- 文档包含需求、架构、代码地图、发布流程。
- 本地 Git 管理项目版本。

## Non-goals For First Version

- 不直接承诺绕过小红书风控。
- 不在没有账号验证的情况下强制全自动点击发布。
- 不依赖昂贵模型作为唯一生成路径。
