# 公开部署

本项目是一个带 API、模型密钥和运营数据的 Node 服务，不能部署为纯静态网页。Docker 镜像会同时运行 React 前端和 Express API。

## 必填环境变量

- `DASHBOARD_PASSWORD`：公开 URL 的运营口令；生产环境未设置时服务会拒绝启动。
- `DEEPSEEK_API_KEY`：仅在云端环境变量中设置，绝不提交到 Git。

建议设置：

- `DASHBOARD_USERNAME=operator`
- `DAILY_CRON=15 9 * * *`
- `MAX_COST_CNY_PER_POST=0.5`

## 数据持久化

将一个持久化磁盘挂载到容器的 `/app/data`。不挂载持久化磁盘时，容器重建会丢失帖子、审核状态和回填数据。

镜像为避免把本机草稿和运行记录复制到云端，首次云端启动会创建一个新的内容池。需要迁移旧内容时，先在本机导出或备份，再由运营人员审核后导入。

## 上线后检查

1. 访问 `/api/health`，应返回 `ok: true`。
2. 打开根路径，浏览器会要求输入运营账号和口令。
3. 创建一条草稿，核验来源、生成封面并保存。
4. 重启服务后确认草稿仍存在，验证持久化磁盘已生效。
5. 小红书最终发布仍由人工在创作服务平台确认，云端不保存小红书登录态。
